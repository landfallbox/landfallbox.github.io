## 本地维护

网站基于 Astro 构建，使用 Github Pages 部署。

常用命令：

| Command | Action |
| :-- | :-- |
| `npm install` | 安装依赖 |
| `npm run dev` | 启动本地开发服务器，默认地址为 `http://localhost:4321` |
| `npm run build` | 构建生产版本到 `./dist/` |
| `npm run preview` | 本地预览构建结果 |
